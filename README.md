# Global Scale Analysis

MB5370 – Techniques in Marine Biology 1  

This repository contains JavaScript scripts developed using Google Earth Engine for the Global Scale Analysis module.

## Workshop 4 – Allen Coral Atlas

**Workshop4ACA.js**

A spatial analysis using Allen Coral Atlas data to investigate suitable research stations for coral sampling by snorkelling, based on accessible reef habitats within a specified distance of each station.

## Assessment – Mapping the World's Deep Ocean Ecosystems

**DeepOceanEcosystems.js**

A global spatial analysis using ETOPO1 bathymetry and seafloor slope to classify four major deep ocean ecosystems:

- Hadal trenches and troughs
- Abyssal plains
- Continental and island slopes
- Submarine canyons

The interactive map also incorporates independently sourced hydrothermal vent locations from the InterRidge Global Database to visualise their distribution in relation to deep ocean ecosystems.
